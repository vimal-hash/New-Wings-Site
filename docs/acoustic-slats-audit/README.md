## Method
- Runtime GLB has no UVs. `scripts/surface-bake/prepare-uv.mjs acoustic-slats` reads only the runtime triangles and derives 1848 planar charts
  (edge-connected faces with the same dominant normal axis, projected along it; 0 overlap splits; 680 charts never face a
  viewpoint and get 1/8 density). The runtime copy gets the same UVs from `/textures/theatre/acoustic-slats/acoustic-slats-uv.bin`; GLBs, positions, normals and topology are unchanged.
- `scripts/blender/surface-bake/bake-item.py acoustic-slats`: Cycles COMBINED direct surface bake of the source material in the disposable copy
  (LeftWall_work_copy.blend, never saved), 512 samples, 7324.4s, all source lights, light linking and occluders.
  Glossy/sheen direction: single bake camera at 0, 22.2, 3.22. Display transform AgX / AgX - Medium High Contrast / exposure 0.45 applied once.
  Every bake triangle matched a runtime triangle (max distance 1.91e-4 m).
- `scripts/surface-bake/encode-item.mjs acoustic-slats`: 8-bit dither, UASTC level 3, RDO 0.25, sRGB, box mipmaps, zstd 19.
- Runtime: `components/corridor/baked-surfaces.tsx`, MeshBasicMaterial, toneMapped false, anisotropy up to 16, one draw call.

- 308 reeded ash slats. The material reads per-object data (Object coordinates), so objects are baked unjoined (308 passes, about 2 hours on this machine); joining would change the per-slat grain.
- At least 12 texels across each slat face; 4 px padding (8 px gutters).

## Limitations
- From the opening eye the slats are mostly hidden by the runtime seats (taller than Blender's), hence the many outliers; the low aisle pose (off the bake eye) is the most useful view: RMSE 3.9 excluding outliers.
- A warm view-dependent highlight streak on the slats beside the seats is weaker in R3F at off-eye angles.

## Reproduce
```
node scripts/surface-bake/prepare-uv.mjs acoustic-slats
blender -b --python scripts/blender/surface-bake/bake-item.py -- acoustic-slats
node scripts/surface-bake/encode-item.mjs acoustic-slats --activate
node scripts/surface-bake/references.mjs acoustic-slats
```
Then capture R3F at each pose into `D:/CodexOutputs/Restoration_20261024/acoustic-slats/reference/<pose>-r3f.png` and run `blender -b --python scripts/blender/surface-bake/compare.py -- acoustic-slats <pose>`.
