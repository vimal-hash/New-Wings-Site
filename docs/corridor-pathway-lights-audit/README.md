## Method
- Runtime GLB has no UVs. `scripts/surface-bake/prepare-uv.mjs corridor-pathway-lights` reads only the runtime triangles and derives 548 planar charts
  (edge-connected faces with the same dominant normal axis, projected along it; 208 overlap splits; 66 charts never face a
  viewpoint and get 1/8 density). The runtime copy gets the same UVs from `/textures/corridor/pathway-lights/corridor-pathway-lights-uv.bin`; GLBs, positions, normals and topology are unchanged.
- `scripts/blender/surface-bake/bake-item.py corridor-pathway-lights`: Cycles COMBINED direct surface bake of the source material in the disposable copy
  (Corridor_prepared_work_copy.blend, never saved), 512 samples, 52.8s, all source lights, light linking and occluders.
  Glossy/sheen direction: single bake camera at -49.892, 105.678, 3.24. Display transform AgX / AgX - Medium High Contrast / exposure -0.65 applied once.
  Every bake triangle matched a runtime triangle (max distance 3.51e-3 m).
- `scripts/surface-bake/encode-item.mjs corridor-pathway-lights`: 8-bit dither, UASTC level 3, RDO 0.25, sRGB, box mipmaps, zstd 19.
- Runtime: `components/corridor/baked-surfaces.tsx`, MeshBasicMaterial, toneMapped false, anisotropy up to 16, one draw call.

- Baked in the prepared runtime-matching corridor scene (Corridor_Runtime_Material_Prepared.blend, disposable copy, never saved); runtime world to Blender is (x,-z,y). Glossy direction: the prepared bend camera. Validation: replaying the ACTIVE_CAMERA bake as pure emission at the bend camera reproduced the source render of the red wall (RMSE 0.32/255), confirming the Light Path > Is Camera Ray fill/tint branches are captured; an ABOVE_SURFACE bake did not (484 outliers) and was rejected.
- Ten slot assemblies (amber diffuser, bronze face, dark interior); 30 objects joined into 2 bake passes; at least 12 texels across thin faces.
- No light intensity, colour or scene lighting is changed.

## Limitations
- At the 6 deg detail pose the glow gradient matches (RMSE 2.1 excluding outliers), but the hottest diffuser line is softened/shifted by 2-3 px by texture filtering, which dominates the thin mask (40% outliers). At normal framing this is sub-pixel.

## Reproduce
```
node scripts/surface-bake/prepare-uv.mjs corridor-pathway-lights
blender -b --python scripts/blender/surface-bake/bake-item.py -- corridor-pathway-lights
node scripts/surface-bake/encode-item.mjs corridor-pathway-lights --activate
node scripts/surface-bake/references.mjs corridor-pathway-lights
```
