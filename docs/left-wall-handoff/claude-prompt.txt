WORKING APPROACH FROM THE CEILING
The accepted ceiling uses one 4096px direct Blender COMBINED surface bake, compressed as KTX2, attached to proper UVs on the actual mesh. Source lighting/reflection direction is captured once; the appearance stays attached to the surface. Its MeshBasicMaterial uses sRGB, toneMapped=false, correct UV channel and anisotropic filtering. It is a fixed-lighting representation, not physically changing reflections or a promise of exact Cycles equivalence at every angle.

Use this as the starting method for this wall if the inspected material supports it. Preserve actual source material detail; do not flatten procedural material channels into arbitrary constants. Preserve original coordinate semantics when introducing bake UVs: changing the active UV layer must not accidentally change the source material's texture mapping. Keep source light linking and all room shadow casters present in the background bake scene. Do not render the wall alone with a different lighting setup.

Prepare and measure clean UVs before baking: no collapsed faces, overlaps, mirrored mistakes or visible stretching; sufficient texel density and island padding. Inspect thin/one-sided faces from the room. A double-sided web material does not fix baking the wrong side: the ceiling previously had a black strip because one closure faced outward. Only correct a disposable bake copy if needed; preserve original and runtime geometry. Use enough samples for a clean result, then inspect the exported texture.

Preserve scene-linear authoring output and apply the ORIGINAL Blender display transform exactly once before encoding a display-colour atlas. Avoid double tone mapping or double lighting in R3F. Use per-island cleanup and safe gutters only where needed, never broad smoothing that erases wall texture. If smooth UV joins show discontinuities, match the actual geometric edges and repair locally. Do not blur across unrelated islands or erase intended source shadows.

KTX2: use the existing basisu tool at D:/New folio/new site code/_tools/basisu/bin/basisu.exe. The ceiling's LDR settings were UASTC level3, sRGB, mipmaps, box mip filter, zstd19. Set texture colour space, UV channel and orientation correctly in the actual loaded GLB. Verify compression visually, not only by bytes.
